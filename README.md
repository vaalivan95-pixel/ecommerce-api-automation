# E-commerce API Automation

Учебный проект для QA-портфолио. Десять интеграционных тестов проверяют публичный API DummyJSON через реальные HTTP-запросы.

## Запуск

Проверено на Node.js 26.12.1. Из корневой папки проекта выполни:

```sh
npm test
```

Тесты используют встроенные `node:test`, `node:assert/strict` и `fetch`. Внешних пакетов нет. Для запуска нужен доступ к `https://dummyjson.com`. Недоступность сервиса или изменение его данных может повлиять на результат.

## Покрытие

Список товаров, обязательные поля, типы данных, цены, получение по ID, ошибка 404, поиск, пагинация, фильтрация по категории и сортировка по цене. Поиск проверяется на известном и отсутствующем товаре. Пагинация сравнивает ID страницы с соответствующим срезом более длинной выдачи.

Сценарии находятся в `tests/products.test.js`. HTTP-запросы и разбор ответов вынесены в `helpers/api.js`.
